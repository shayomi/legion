# Decisions

Key decisions that emerge from brainstorm sessions are recorded here as standalone notes.
These complement the ADRs in `agents/cto/decision-log.md` — this folder captures
product and business decisions, the CTO log captures technical/architectural ones.

## Decision Record Template

```markdown
## Decision: [Short title]
**Date:** YYYY-MM-DD
**Session ref:** [Brainstorm session ID if applicable]
**Decision maker:** Legion | TITAN | COMPASS | [agent]
**Status:** Decided | Revisiting | Superseded

### Context
What situation required a decision?

### Decision
What was decided?

### Rationale
Why this option over alternatives?

### Consequences
What changes as a result of this decision?

### Review date
When should this decision be reconsidered?
```
