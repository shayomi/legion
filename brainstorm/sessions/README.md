# Brainstorm Sessions

Every brainstorm session Legion runs is stored here.

## How to start a session

```bash
legion brainstorm "Your feature description here"
```

This creates a session document pre-structured with a perspective slot for every relevant agent.
Fill in each agent's section, then use the output to drive the spec documents.

## File naming

`YYYY-MM-DD-feature-slug.md`

## Session lifecycle

1. **Created** — `legion brainstorm` generates the template
2. **In Progress** — Fill in each agent's perspective
3. **Complete** — All perspectives captured, key decisions recorded
4. **Archived** — Synced to Obsidian, linked from project note

---

_Sessions here automatically sync to Obsidian/Legion/Brainstorms/ on `legion memory sync`_
