# Second Brain — Local Notes

Legion's own local note store. Everything here is also synced to Obsidian.

This is where MEMORY stores:
- Notes created with `legion memory note "Title"`
- Synthesised insights from completed projects
- Pattern recognition across engagements
- Learning logs from agent skill acquisition

## Note naming

`YYYY-MM-DD-title-slug.md`

## The Zettelkasten approach

Legion's second brain follows a modified Zettelkasten:
- **Fleeting notes** — raw captures from sessions (`legion memory log`)
- **Literature notes** — structured notes from research (ORACLE briefs)
- **Permanent notes** — distilled, evergreen insights (what Legion actually knows)
- **Project notes** — active project context (linked to specs and builds)

Each note links to related notes. MEMORY maintains the links.
The value compounds over time.
