# Completed Builds

Shipped features are archived here.

When a feature ships:
1. Move its folder from `active/` to `completed/`
2. Add a `retrospective.md` — what went well, what didn't, what to change
3. Run `legion memory sync` to push the retrospective to Obsidian
4. MEMORY agent will link it from the project note
