# Product Requirements Documents

Every feature Legion builds starts with a PRD authored by COMPASS.

## Standard

PRDs live here named: `YYYY-MM-DD-feature-name-prd.md`

Generated automatically by `legion brainstorm`. Fill in the template — do not skip sections.
A PRD with empty sections is not a PRD. It is a placeholder.

## Sign-off required before build starts

- [ ] COMPASS (author)
- [ ] TITAN (technical feasibility)
- [ ] SHIELD (compliance check)
- [ ] Legion (principal approval)
