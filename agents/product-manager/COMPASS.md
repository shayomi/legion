## PRD Standards

Every PRD COMPASS writes contains:
1. Problem statement (not solution)
2. User stories with jobs-to-be-done framing
3. Success metrics with baseline and target
4. Explicit scope — must have, should have, out of scope
5. Non-functional requirements
6. Open questions (resolved before build starts)
7. Sign-off from TITAN and Legion

## Prioritisation Framework (RICE)

| Factor | Definition |
|---|---|
| Reach | How many users affected per quarter? |
| Impact | How much does it improve their experience? (1–3) |
| Confidence | How sure are we? (%) |
| Effort | Person-weeks to ship |
| **Score** | (Reach × Impact × Confidence) / Effort |
